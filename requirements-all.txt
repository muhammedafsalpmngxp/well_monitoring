# requirements-all.txt — every Python dependency in this repo, in ONE env
# =============================================================================
# Merges these files (left unchanged):
#   requirements.txt                                   (sso/ Django SSO app)
#   backend/requirements.txt                           (Jenny voice API)
#   smartops/shared/python/requirements-base.txt       (smartops_shared)
#   smartops/services/python/agent_runtime/requirements.txt
#   smartops/services/python/etl/requirements.txt
#   smartops/services/python/jenny_ai/requirements.txt
#   smartops/services/python/predictive/requirements.txt
#   smartops/services/python/anomaly/requirements.txt
#   smartops/services/python/crew_optimizer/requirements.txt
#   smartops/services/python/vision/requirements.txt
#
# Usage (Python 3.11 — the version every Dockerfile uses):
#   py -3.11 -m venv .venv
#   .venv\Scripts\Activate.ps1
#   pip install -r requirements-all.txt
#
# Version conflicts between the per-service files, resolved here:
#   * langchain-openai: agent_runtime pins 1.6.7, jenny_ai pins 0.2.8 with
#     langchain 0.3.7. They cannot share an env (langchain-core 1.x vs 0.3.x).
#     Kept 1.6.7 (agent_runtime is the live agent builder). jenny_ai imports
#     `langchain.schema` inside try/except, so in this env its /chat endpoint
#     is disabled; /transcribe still works. Use jenny_ai's own requirements
#     file in a separate venv if you need its /chat.
#   * orjson: the base file pins 3.10.10, which conflicts with langgraph.
#     Nothing imports orjson directly, so it is left to the resolver.
#   * fastapi/uvicorn/python-multipart: backend/ pins older versions; the
#     newer smartops versions are used.
#   * pyodbc: etl pins 5.1.0, agent_runtime 5.3.0; 5.3.0 is used.
#
# Non-pip prerequisites (install separately):
#   * Python 3.11
#   * Microsoft ODBC Driver 18 for SQL Server   (pyodbc: etl, agent_runtime)
#   * ffmpeg on PATH                            (faster-whisper: backend/, jenny_ai)
#   * .NET SDK 8.0.425                          (global.json; all services net8.0)
#   * Node.js 22                                (smartops/TWise.Frontend.Tenant, Angular 22)
#   * Node.js 18.13+ / npm 9+                   (root legacy app, Angular 17)
#   * SQL Server 2022, Redis, TimescaleDB       (or `docker compose up` in smartops/)
# =============================================================================
