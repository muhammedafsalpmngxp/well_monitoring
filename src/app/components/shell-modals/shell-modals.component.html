One Supervisor AI sits at the top. When a request comes in, the supervisor decides what to do and delegates the work to one or more specialised agents — for example, Agent 1 reads field data and Agent 2 predicts delays. You can add as many specialised agents as the job needs; the supervisor keeps them coordinated.
