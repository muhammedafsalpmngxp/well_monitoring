How it works

  1. Pick the source chart. A click on its bar, slice or table row drives the other visuals.
  2. Pick the charts and tiles that should react to it, then press Add.
  3. For each one choose Filter (show only the matching records), Highlight (keep everything and emphasise the matching records) or None.
  4. Press Save Configuration, then save the dashboard.

Why are some items disabled?

A chart or tile can only react to the source if it uses the same data. It is enabled when:

  • it is built on the same table or view as the source chart, or
  • its data has the same field the source chart groups by (for example location) and contains the same values.

Tiles are disabled until a source chart is chosen, because a tile has no bars to click. Charts without a category field cannot be a source. "Checking data…" means the data is still being compared.

To enable a disabled item

  • Choose a different source chart: the enabled list changes with the source.
  • Or build the chart or tile on the same table or view in the Chart Builder / Tile Builder.
  • The field the source groups by (shown as picks under the title) must exist in that table or view.
